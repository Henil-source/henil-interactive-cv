# HENIL — Interactive CV

A responsive, bilingual (English/French), dark-theme interactive CV built with plain HTML, CSS and JavaScript.

## Open locally
1. Open this folder in VS Code.
2. Open `index.html` with a browser, or use the VS Code Live Server extension.
3. Everything works without a build step.

## Publish
Recommended workflow:
1. Create a GitHub repository named `henil-interactive-cv`.
2. Upload all files in this folder.
3. Import the repository into Vercel.
4. Deploy.
5. Add `henilzaveri.com` as a custom domain in Vercel and follow the DNS instructions it provides.
6. Keep the Wix domain purchase, but do not assign the domain to a Wix site.

## Notes
- The profile image and certificate PDFs are included in `assets/`.
- English/French language choice is saved in the browser.
- Reduced-motion preference is available from the top navigation.
- Approximate euro conversions are used only for the Baazigar presentation; the source competition amounts were in INR.
